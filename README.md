# Rhema legal policies

This repository publishes the privacy policy and terms of service for Rhema, an AI-assisted Bible tutoring app.

- [Privacy Policy](https://noah-ing.github.io/rhema-legal/privacy.html)
- [Terms of Service](https://noah-ing.github.io/rhema-legal/terms.html)

Both documents currently list an effective date of February 8, 2026. The
repository is structured to serve them as static pages through GitHub Pages.

This repository contains public policy documents only. It does not contain the Rhema application, prove that the described controls are implemented, or provide a reusable legal template. The documents should be reviewed whenever the application's providers, data practices, safety controls, or subscription terms change.

Before publishing a policy change, the service owner should verify every stated data flow, retention period, security control, age-related practice, subscription term, contact address, jurisdiction, and effective date against the live app. Legal review remains an owner responsibility.

No open-source license is granted for these documents.
